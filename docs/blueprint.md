# **App Name**: Dalilke Debt Manager

## Core Features:

- Secure Login: Delegate Login to securely access the app.
- Customer List: View a list of associated customers.
- Debt Registration: Record new debts, including amount, description, due date, and invoice copy URL.
- Payment Registration: Record customer payments, including amount, payment method, and a copy of the receipt voucher URL.
- Account Statement: Display an account statement for each customer.
- Debt Age Report: Generate a debt age report, categorizing debts into 0-30, 31-60, 61-90, and 90+ days.

## Style Guidelines:

- Primary color: Moderate blue (#5DADE2) for trust and reliability.
- Background color: Light gray (#F0F4F8), providing a clean and neutral backdrop.
- Accent color: Muted violet (#8E44AD) for interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) for clear readability in both Arabic and other languages.
- Support for right-to-left (RTL) layouts for Arabic language users.
- Use minimalist and professional icons.
- Subtle transitions to confirm user actions, like recording new debt or new payment, enhancing the experience without being distracting.
